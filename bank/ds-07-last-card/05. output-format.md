Print the discarded cards on the first line, in the order they were discarded,
separated by single spaces. There are `N - 1` of them.

Print the remaining card on the second line.

**When `N` is 1 nothing is discarded, so the first line is empty.**

### Example

Input

```
4
10 20 30 40
```

Output

```
10 30 20
40
```
