The first line contains the number of trees, `T`.

Each tree is given as two lines:

- a line with the number of tokens, `M`
- a line with the `M` tokens in **level order**, separated by spaces. Each
  token is either a node's key or `#`, meaning there is no node in that
  position. **The children of a missing node are not listed.**

### Example

```
3
2 1 3
```

reads as: root `2` with children `1` and `3`.
