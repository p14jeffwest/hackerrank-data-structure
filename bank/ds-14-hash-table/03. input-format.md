The first line contains the table size and the number of commands `M`,
separated by a space.

Each of the next `M` lines contains one command.

| Command | Meaning |
|---|---|
| `put k v` | Store value `v` under key `k`. No output. |
| `get k` | Print the value stored under `k`, or `-1`. |
| `remove k` | Delete key `k`. No output. |
| `print` | Print every bucket. |
