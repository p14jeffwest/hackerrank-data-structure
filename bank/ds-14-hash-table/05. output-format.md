Print one line for each `get` and `print` command.

`print` shows every bucket from slot 0, in the form `i: k=v k=v`, with the
buckets separated by ` |`. An empty bucket shows just its number.

**The formatting is already written.** You only have to fill the buckets
correctly.

### Example

Input

```
10 5
put 1 100
put 11 200
get 1
get 5
print
```

Output

```
100
-1
0: |1: 1=100 11=200 |2: |3: |4: |5: |6: |7: |8: |9:
```

Both `1` and `11` land in slot 1, so they share its chain, in the order they
were put. Key `5` was never stored, so `get` gives `-1`.
