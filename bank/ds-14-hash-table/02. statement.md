## A Chaining Hash Table

A hash table sends each key to a slot and stores it there. Two keys can land
in the same slot, and **chaining** handles that by keeping a list at each
slot.

Implement four methods of `HashTable`:

```java
protected int hash(int key)          // which slot, using key % size
public void put(int key, int value)  // store; replace the value if the key is there
public int get(int key)              // the value, or -1 if absent
public void remove(int key)          // delete the key
```

**Keys may be negative**, and in Java `-7 % 10` is `-7`, not `3`.

A key already present keeps its **position** in its chain and only its value
changes. A new key goes at the **end** of its chain.

The bucket contents are part of the answer, so the table has to be the
chaining one described here.

Available: `bucketAt(i)` gives the list at slot `i`, `tableSize()` gives the
number of slots.
