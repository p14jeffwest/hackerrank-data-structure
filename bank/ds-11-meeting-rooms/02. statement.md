## Meeting Rooms

Each meeting has a start time and an end time. Meetings running at the same
time need separate rooms. How many rooms are needed at least?

```
(0,30) (5,10) (15,20)   ->  2
(7,10) (2,4)            ->  1
```

In the first case `(0,30)` and `(5,10)` run together, so two rooms are needed;
`(15,20)` reuses the room `(5,10)` has finished with.

**A meeting ending exactly when another starts does not overlap it.** The same
room takes both.

```java
static int minMeetingRooms(int[][] meetings)
```

`meetings[i]` is `{start, end}`, in no particular order. You may rearrange the
array.
