For each test case, print all $2^n$ subsets, one per line, in the order
described above. The elements of a subset are separated by single spaces, and
the empty subset is printed as `(empty)`.

Test cases follow one another with no separator.

### Example

Input

```
2
2
2 1
3
3 1 2
```

Output

```
(empty)
1
1 2
2
(empty)
1
1 2
1 2 3
1 3
2
2 3
3
```
