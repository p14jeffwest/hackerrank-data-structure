## Generating Subsets

Given a set of `n` distinct integers, list **every** subset. A set of `n`
elements has $2^n$ of them, counting the empty subset and the whole set.

For each element there are two choices -- leave it out, or put it in -- so the
recursion branches in two at every step and the leaves of that tree are the
subsets.

### The order is fixed

The subsets have to come out in a definite order, so:

- inside each subset, the elements are in **ascending** order;
- the subsets are in **lexicographic** order, compared element by element,
  with the shorter one first when it is a prefix of the other.

For `{3, 1, 2}` that gives:

```
(empty)
1
1 2
1 2 3
1 3
2
2 3
3
```

**The input arrives in no particular order.** Sorting the `n` values once at
the start is enough; there is no need to sort $2^n$ subsets afterwards.
