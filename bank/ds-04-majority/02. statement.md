## The Majority Element

An element is the **majority element** of a list when it appears **strictly
more than half** the time. In a list of 7, that means at least 4 occurrences.

```
[2, 2, 1, 1, 1, 2, 2]   ->   2   (four of seven)
```

Every list in this problem is guaranteed to have one. Return it.

Complete the `majorityElement` method:

```java
public static int majorityElement(ListInterface<Integer> list)
```

`Array_List<T>` is provided in full, along with all input and output handling.

**The list must come back unchanged.** Reading it is a query, not an edit --
`get` does not modify a list, and neither should this. The driver compares the
list before and after your call, and prints `modified` in place of the answer
if it changed.
