For each test case, print the majority element on its own line.

If your method changed the list it was given, the driver prints `modified` for
that test case instead.

**The output handling is already written.** You only have to return the right
value.

### Example

Input

```
2
3
3 2 3
7
2 2 1 1 1 2 2
```

Output

```
3
2
```

In the first list, `3` fills two of the three slots. In the second, `2` fills
four of the seven.
