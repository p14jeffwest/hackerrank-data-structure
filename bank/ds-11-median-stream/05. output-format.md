Print one line for each `median` and `size` command.

A median is printed with **one decimal place** -- `2.0`, `1.5`, `-0.5`. On an
empty stream the line reads `empty`.

**The formatting is already written.** You only have to return the value.

### Example

Input

```
6
add 1
add 2
median
add 3
median
size
```

Output

```
1.5
2.0
3
```
