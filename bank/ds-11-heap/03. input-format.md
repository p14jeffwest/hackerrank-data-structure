The first line contains the number of commands, `M`.

Each of the next `M` lines contains one command.

| Command | Meaning |
|---|---|
| `push x` | Add `x`. No output. |
| `pop` | Print the smallest value and remove it. |
| `peek` | Print the smallest value. |
| `size` | Print the number of values held. |
| `print` | Print the heap array from index 0. |

`pop` and `peek` on an empty heap print `empty`.
