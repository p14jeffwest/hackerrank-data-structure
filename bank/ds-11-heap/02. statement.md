## A Min-Heap

A **min-heap** is a complete binary tree in which every node is smaller than
its children, kept in an array: the children of index `i` sit at `2i + 1` and
`2i + 2`, and its parent at `(i - 1) / 2`.

Implement two methods of `MinHeap`:

```java
public void push(int x)   // add x
public int pop()          // remove and return the smallest
```

**`push`** puts the new value at the end of the array -- which keeps the shape
but may break the order -- and then moves it **up** while it is smaller than
its parent.

**`pop`** takes the root, moves the **last** value into the root's place, and
then moves that value **down**, each step swapping with the **smaller** of its
two children.

The array itself is part of the answer, so both must be done exactly this way.

Available: `get`, `set`, `addLast`, `removeLast`, `swap`, `size`, `parent(i)`,
`left(i)`, `right(i)`.
