Print one line for each `pop`, `peek`, `size` and `print` command.

`print` shows the heap array from index 0, separated by single spaces. An
empty heap prints an empty line.

### Example

Input

```
10
push 5
print
push 3
print
push 8
print
push 1
print
push 6
print
```

Output

```
5
3 5
3 5 8
1 3 8 5
1 3 8 5 6
```

Pushing `3` puts it at index 1 and it climbs above `5`. Pushing `1` puts it at
index 3, above `5`, then above `3`.
