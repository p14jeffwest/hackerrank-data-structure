On the first line, print the minimum number of moves.

From the second line on, print the moves one per line in the form `A -> C`:
the starting peg, then `->`, then the destination peg, with a single space on
each side of the arrow.

### Example

Input

```
3
```

Output

```
7
A -> C
A -> B
C -> B
A -> C
B -> A
B -> C
A -> C
```
