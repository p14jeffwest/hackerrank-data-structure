## Tutorial 1: Hello, Java!

Print the following line:

```java
System.out.println("Hello, Java!");
```

This is the first problem, so the goal is to get used to the submission flow:

1. Write the code in the template.
2. Compile and test it.
3. Submit when the sample output matches.

Important notes:
- The class name must be `Solution`.
- Write comments in English only, using plain ASCII characters.
