## Path Sum

Consider a path that starts at the **root** and ends at a **leaf**. The sum of
the values along it is that path's **path sum**.

Given several targets, report for each whether some root-to-leaf path has that
sum.

**A path must end at a leaf.** A leaf has no children at all; stopping at a
node that still has one child is not a path.

### Example

```
        5
       / \
      3   8
     / \    \
    1   4    9
```

This tree has three path sums: `9` (5-3-1), `12` (5-3-4) and `22` (5-8-9).

| target | Result |
|---|---|
| `12` | `true` |
| `10` | `false` |

Node values may be **negative**, so a running total can fall as well as rise.

Building the tree and all input and output handling are provided. Fill in:

```java
static boolean hasPathSum(Node node, int target)
```
