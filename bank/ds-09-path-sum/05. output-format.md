For each target, print `true` or `false` on its own line.

**The output handling is already written.** You only have to return the right
value.

### Example

Input

```
7
5 3 8 1 4 # 9
5
12 10 9 22 13
```

Output

```
true
false
true
true
false
```

`12` is 5-3-4, `9` is 5-3-1, and `22` is 5-8-9. No path gives `10` or `13`.
