The first line contains the number of commands, `Q`.

Each of the next `Q` lines contains one command.

| Command | Meaning |
|---|---|
| `add X` | Append `X` to the end. No output. |
| `addAt i X` | Insert `X` at position `i`. No output. |
| `removeAt i` | Remove the node at position `i` and print its data. |
| `removeValue X` | Remove the first node holding `X`. Prints `1` if one was removed, `0` if `X` was not there. |
| `get i` | Print the data at position `i`. |
| `indexOf X` | Print the position of the first node holding `X`, or `-1`. |
| `size` | Print the number of nodes. |
| `print` | Print the whole list. |

A position outside the range that command allows prints `error` instead.
