Print one line for every command that produces output (`removeAt`,
`removeValue`, `get`, `indexOf`, `size`, `print`), plus one line reading
`error` for every out-of-range position.

`print` shows the list in the form `[10, 15, 20]`. An empty list prints `[]`.

**The output handling is already written.** You only have to make the three
methods change and search the list correctly.

### Example

Input

```
13
add 10
add 20
add 30
print
addAt 1 15
print
removeAt 0
print
indexOf 30
get 5
addAt 3 99
print
size
```

Output

```
[10, 20, 30]
[10, 15, 20, 30]
10
[15, 20, 30]
2
error
[15, 20, 30, 99]
4
```

`addAt 1 15` re-points two references and moves nothing. `removeAt 0` returns
`10` and advances `head`. `get 5` is out of range, but `addAt 3 99` is not:
the list holds three nodes, and position 3 is the append position.
