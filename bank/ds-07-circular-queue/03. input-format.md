The first line contains the queue capacity `C` and the number of commands `Q`,
separated by a space.

Each of the next `Q` lines contains one command.

| Command | Meaning |
|---|---|
| `enqueue X` | Add `X` at the rear. Prints `full` if the queue is full. |
| `dequeue` | Print the front element and remove it. |
| `front` | Print the front element. |
| `size` | Print the number of elements. |
| `empty` | Print `1` if the queue is empty, `0` if not. |
| `full` | Print `1` if the queue is full, `0` if not. |
| `clear` | Remove everything. No output. |

`dequeue` and `front` on an empty queue print `empty`.
