Print one line for every command that produces output (`enqueue` when the
queue is full, `dequeue`, `front`, `size`, `empty`, `full`).

`dequeue` and `front` print `empty` when there is nothing in the queue, and
`enqueue` prints `full` when there is no room. If your code reads outside the
array instead, that line reads `crash`.

**The output handling is already written.** You only have to make the three
methods work.

### Example

Input

```
4 16
enqueue 1
enqueue 2
dequeue
dequeue
enqueue 3
enqueue 4
enqueue 5
enqueue 6
full
size
front
dequeue
dequeue
dequeue
dequeue
empty
```

Output

```
1
2
1
4
3
3
4
5
6
1
```

Capacity is 4. After the two dequeues, `front` sits at index 2, so `enqueue 5`
writes at index 0 and `enqueue 6` at index 1 -- the two slots emptied at the
start, reused. The queue then holds four elements and reports itself full.
