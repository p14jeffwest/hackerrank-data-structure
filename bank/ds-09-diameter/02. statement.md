## The Diameter of a Binary Tree

The **diameter** of a binary tree is the number of **edges** on the longest
path between any two of its nodes. **That path need not pass through the
root.**

### Example

```
        1
       / \
      2   3
     / \
    4   5
```

The diameter is `3`, along `4 - 2 - 1 - 3` (or `5 - 2 - 1 - 3`): three edges.

| Tree | Diameter |
|---|---|
| the tree above | 3 |
| a single node | 0 |
| `1 -> (2 -> (3), null)` | 2 |

Note the units. The diameter is counted in **edges**, so a single node has
diameter 0. Section 9.5 measures depth in nodes; this is not that.

Building the tree and all input and output handling are provided. Fill in:

```java
static int diameter(Node root)
```

The obvious approach -- at every node, add the heights of its two subtrees and
keep the largest -- gives the right answer and recomputes the same heights
once for every ancestor. With half a million nodes that is not affordable.
