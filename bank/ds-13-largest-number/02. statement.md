## Building the Largest Number

Given non-negative integers, arrange them so that writing them one after
another gives the **largest possible number**. Report it as a string.

```
3 30 34 5 9  ->  "9534330"
10 2         ->  "210"
0 0          ->  "0"
```

**Sorting by value does not work.** For `3` and `30`, writing `3` first gives
`330` and writing `30` first gives `303`, so `3` comes first even though `30`
is the larger number. What decides the order is how the two look **written
side by side**.

If every number is `0`, the answer is `"0"`.

```java
static String largestNumber(int[] nums)
```

The result can run to hundreds of thousands of digits, so build it as a
string.
