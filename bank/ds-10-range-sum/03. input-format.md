The first line contains the number of tokens, `M`.

The second line contains the `M` tokens of the tree in **level order**,
separated by spaces. Each token is either a node's key or `#`, meaning there
is no node in that position. **The children of a missing node are not
listed.**

The third line contains the number of queries, `Q`.

Each of the next `Q` lines contains one query: `low` and `high`, separated by
a space.
