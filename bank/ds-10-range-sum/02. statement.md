## Range Sum in a BST

Given a binary search tree and a range `[low, high]`, add up every key `k` in
the tree with `low <= k <= high`. Both ends are included.

```
      10
     /  \
    5    15
   / \     \
  3   7    18

low = 7, high = 15  ->  7 + 10 + 15 = 32
```

Answer many such ranges against the same tree.

```java
static long rangeSum(Node root, int low, int high)
```

The tree is a valid BST. Walking all of it for every range is too slow -- but
the BST rule tells you where the answer **cannot** be.
