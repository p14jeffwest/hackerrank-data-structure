## Building an Array-Based List

An array holds values. A list adds positions that stay in order when you insert
or remove one in the middle. An array has no spare gaps, so making room at
position `i` means physically moving everything behind it.

Three methods of `Array_List<T>` are left blank. Fill them in.

| Method | What it must do |
|---|---|
| `add(int givenPosition, T newEntry)` | Insert `newEntry` at that position. The element that was there, and everything after it, moves back one slot. |
| `T remove(int givenPosition)` | Remove the element at that position and return it. Everything after it moves forward one slot. |
| `int indexOf(T anEntry)` | Return the position of `anEntry`, or `-1` if it is not in the list. |

Everything else is provided: the `ListInterface<T>` declaration, the
constructors, `add` at the end, `get`, `size`, `toString`, the private helpers
`checkIntegrity`, `checkPosition` and `ensureCapacity`, and all input and
output handling.

### Positions

Positions start at **0**, and a position is valid only when it refers to an
element that already exists: `0 <= givenPosition < size()`. Anything else
prints `error`. So on a list of size 3, `addAt 3` is an error, and on an empty
list every position is out of range. `checkPosition` already throws the right
exception; calling it is all you need.
