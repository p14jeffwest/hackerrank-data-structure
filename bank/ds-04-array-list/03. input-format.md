The first line contains the number of commands, `Q`.

Each of the next `Q` lines contains one command.

| Command | Meaning |
|---|---|
| `add X` | Append `X` to the end. No output. |
| `addAt i X` | Insert `X` at position `i`. No output. |
| `removeAt i` | Remove the element at position `i` and print it. |
| `removeValue X` | Remove the first element equal to `X`. Prints `1` if one was removed, `0` if `X` was not there. |
| `get i` | Print the element at position `i`. |
| `indexOf X` | Print the position of the first element equal to `X`, or `-1`. |
| `size` | Print the number of elements. |
| `print` | Print the whole list. |

For `addAt`, `removeAt` and `get`, a position outside `0 <= i < size()` prints
`error` instead.
