Print one line for every command that produces output (`removeAt`,
`removeValue`, `get`, `indexOf`, `size`, `print`), plus one line reading
`error` for every out-of-range position.

`print` shows the list in the form `[10, 15, 20]`. An empty list prints `[]`.

**The output handling is already written.** You only have to make the three
methods change and search the list correctly.

### Example

Input

```
12
add 10
add 20
add 30
print
addAt 1 15
print
removeAt 0
print
indexOf 30
get 5
addAt 3 99
size
```

Output

```
[10, 20, 30]
[10, 15, 20, 30]
10
[15, 20, 30]
2
error
error
3
```

`addAt 1 15` moves `20` and `30` back one slot and drops `15` into the gap.
`removeAt 0` returns `10` and pulls the rest forward. The list then holds three
elements at positions 0, 1 and 2, so `get 5` and `addAt 3 99` are both out of
range.
