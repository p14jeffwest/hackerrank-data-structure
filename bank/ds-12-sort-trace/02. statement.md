## The Array Partway Through Selection Sort

Selection sort settles one position at a time, from the front:

- take the next position,
- find the **smallest value in the rest of the array**,
- **swap** it into that position,
- and never touch that position again.

Settling one position is one **pass**. Report the array after exactly `K`
passes.

### Example

Starting from `5 2 4 1 3`:

| Pass | Position | Smallest in the rest | Array afterwards |
|---|---|---|---|
| 1 | 0 | `1` | `1 2 4 5 3` |
| 2 | 1 | `2`, already there | `1 2 4 5 3` |
| 3 | 2 | `3` | `1 2 3 5 4` |

So `K = 3` gives `1 2 3 5 4`, and `K = 0` gives the array unchanged.

**A value already in place still uses up a pass.**

```java
static int[] selectionPasses(int[] a, int k)
```

Do not modify the array you are given.
