## Process Priorities

An operating system keeps waiting processes in a queue and runs the most
important one first. It works like this:

1. Take the process at the **front** of the queue.
2. If **any** process still in the queue has a **strictly higher** priority,
   put this one back at the **rear**.
3. Otherwise, run it.

Processes of **equal** priority do not displace each other.

Given the priorities and the starting position of one process you care about,
report **in which position that process runs**. The first process to run is
position 1.

### Example

Priorities `2 1 3 2`, tracking the process at position 2 (priority 3).
Writing each process as `(position, priority)`:

| Taken | Higher priority waiting? | Action | Queue afterwards |
|---|---|---|---|
| `(0,2)` | yes, 3 | to the rear | `(1,1) (2,3) (3,2) (0,2)` |
| `(1,1)` | yes, 3 | to the rear | `(2,3) (3,2) (0,2) (1,1)` |
| `(2,3)` | no | **runs, position 1** | `(3,2) (0,2) (1,1)` |

The tracked process runs first, so the answer is `1`.
