## The k-th Node from the End

Counting from the front of a linked list is easy: follow `next` until you have
taken enough steps. Counting from the **back** is not, because the links only
run one way and there is nothing to walk backward along.

Given the first node of a list and a positive integer `k`, return the data of
the `k`-th node from the end. `k = 1` means the last node.

```
1 -> 2 -> 3 -> 4 -> 5     k = 2   ->   4
```

Complete the `kthFromEnd` method:

```java
public static int kthFromEnd(Node head, int k)
```

The `Node` class and all input and output handling are provided. **You are
given only `head`** -- the length of the list is not passed in, and the driver
keeps no reference to the last node.

```java
class Node {
    int data;
    Node next;
}
```
