Print two lines:

1. the preorder traversal of the tree, separated by single spaces
2. the height of the tree, counted in **edges** (a single node is 0)

**The output handling is already written.** You only have to return the root.

### Example

Input

```
7
1 2 3 4 5 6 7
```

Output

```
4 2 1 3 6 5 7
2
```
