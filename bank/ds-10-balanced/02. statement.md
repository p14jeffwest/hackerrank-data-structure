## Building a Balanced BST

Given keys in ascending order, build a binary search tree of **minimum
height**.

Inserting them one by one in the order given would produce a spine of height
`n - 1`. Taking the middle key as the root instead splits the rest into two
halves of nearly equal size, and repeating that on each half gives the
shallowest tree the keys allow.

```
[1, 2, 3, 4, 5, 6, 7]  ->        4
                                / \
                               2   6
                              / \ / \
                             1  3 5  7
```

**For each range, take `nums[(lo + hi) / 2]` as the root** -- integer
division, so the left of the two middles when the range holds an even number
of keys. Other choices balance the tree just as well but build a different
one.
