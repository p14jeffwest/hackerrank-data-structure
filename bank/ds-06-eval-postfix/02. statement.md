## Evaluating a Postfix Expression

In the notation we usually write, the operator sits between its operands:
`(3 + 4) * 5`. In **postfix** notation it comes after them: `3 4 + 5 *`. The
order of evaluation is then fixed without any parentheses, which is why
machines prefer it.

A stack evaluates it in one pass. Push each number; on an operator, take two
values off, combine them, and push the result back. When the tokens run out,
the single value left is the answer.

```
3  ->  push          [3]
4  ->  push          [3, 4]
+  ->  take 4 and 3, push 7       [7]
5  ->  push          [7, 5]
*  ->  take 5 and 7, push 35      [35]
```

Evaluate each expression and print its value.

### Two things to be careful about

**Which operand is which.** The two values you take off do not arrive in
writing order. `5 3 -` is `5 - 3`, not `3 - 5`. Addition and multiplication do
not notice; subtraction and division do.

**Which tokens are operators.** `-` is the subtraction operator. `-11` is a
negative number.

Division is integer division as Java performs it, truncating toward zero.
