## Merging Two Sorted Arrays

Two arrays are given, each already in ascending order. Merge them into one
ascending array.

```
[1,3,5,7]  [2,4,6]   ->   1 2 3 4 5 6 7
[1,1,2]    [1,3]     ->   1 1 1 2 3
```

This is the **merge step of merge sort**. Walk one index along each array and
take whichever front value is smaller, so each array is swept exactly once and
the whole thing costs $O(n + m)$.

```java
static int[] mergeSorted(int[] a, int[] b)
```

Write the merge yourself; do not call a sort library.

Either array may be empty.
