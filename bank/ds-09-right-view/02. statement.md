## Right Side View of a Binary Tree

Stand to the right of a binary tree and look at it. At each level you see one
node -- the rightmost one at that level -- and everything behind it is hidden.
List what you see, from the top down.

### Example

```
        1
       / \
      2   3
       \   \
        5   4
```

The view is `1 3 4`. Node `5` is hidden: it sits at the same level as `4`, to
its left.

### The rightmost node at a level is not always a right child

```
        1
       /
      2
     /
    3
```

Here the view is `1 2 3`. Nothing has a right child at all, but at each level
there is exactly one node, so every one of them is visible.

Building the tree and all input and output handling are provided. Fill in:

```java
static void rightSideView(Node root, List<Integer> out)
```

Append the values you see, from the top down, to `out`.
