The first line contains the number of tokens, `M`.

The second line contains the `M` tokens of the tree in **level order**,
separated by spaces. Each token is either a node's value or `#`, meaning there
is no node in that position. **The children of a missing node are not
listed.**

### Example

```
7
5 3 8 1 4 # 9
```

reads as: root `5`; its children `3` and `8`; then `3`'s children `1` and `4`;
then `8`'s children, the first missing and the second `9`.
