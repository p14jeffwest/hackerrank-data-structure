## Tutorial 3: Sum of N Integers

Read `N` integers and print their sum.

This problem is about reading many values efficiently and using a type large enough for the total.

Use `BufferedReader` to read input, then parse the numbers and add them.

```java
BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
int n = Integer.parseInt(br.readLine().trim());

StringTokenizer st = new StringTokenizer(br.readLine());
long sum = 0;
for (int i = 0; i < n; i++) {
    sum += Integer.parseInt(st.nextToken());
}

System.out.println(sum);
```

Use `long` for the sum, not `int`.
