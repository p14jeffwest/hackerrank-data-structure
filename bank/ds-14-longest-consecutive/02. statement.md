## The Longest Consecutive Run

Given integers in no particular order, find the length of the longest run of
**consecutive** values among them. The values need not be adjacent in the
array.

| Values | Answer | Run |
|---|---|---|
| `100 4 200 1 3 2` | `4` | 1, 2, 3, 4 |
| `0 3 7 2 5 8 4 6 0 1` | `9` | 0 through 8 |
| `5 5 6 6 7 7` | `3` | 5, 6, 7 -- a repeat does not extend a run |

An empty array gives `0`.

```java
static int longestConsecutive(int[] nums)
```

**Do not sort.** $O(n)$ is expected: a hash set answers "is this value
present?" in constant time, which is what replaces the sorting.

Note that a run of length `L` can be reached from any of its `L` members. Take
care not to walk it `L` times.
