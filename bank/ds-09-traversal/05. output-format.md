Print four lines:

1. the preorder traversal
2. the inorder traversal
3. the postorder traversal
4. the level-order traversal

Each line lists the values of the nodes in the order visited, separated by
single spaces.

**The output handling is already written.** You only have to fill `out`
correctly in each method.

### Example

Input

```
7
5 3 8 1 4 # 9
```

Output

```
5 3 1 4 8 9
1 3 4 5 8 9
1 4 3 9 8 5
5 3 8 1 4 9
```
