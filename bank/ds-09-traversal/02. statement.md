## Tree Traversals

There is more than one order in which to visit every node of a binary tree
exactly once. Implement four of them.

| Traversal | Visit order |
|---|---|
| **preorder** | the node itself, then the left subtree, then the right |
| **inorder** | the left subtree, then the node itself, then the right |
| **postorder** | the left subtree, then the right subtree, then the node |
| **level order** | level by level from the top, left to right within a level |

The first three do the same three things and differ only in the order. The
fourth is not like them at all: it visits everything at one depth before
anything deeper, and following a branch to the bottom is exactly what it must
not do.

### Example

```
        5
       / \
      3   8
     / \    \
    1   4    9
```

| Traversal | Result |
|---|---|
| preorder | `5 3 1 4 8 9` |
| inorder | `1 3 4 5 8 9` |
| postorder | `1 4 3 9 8 5` |
| level order | `5 3 8 1 4 9` |

Building the tree and all input and output handling are provided. Fill in the
four methods, appending the value of each node you visit to `out`:

```java
static void preorder(Node node, List<Integer> out)
static void inorder(Node node, List<Integer> out)
static void postorder(Node node, List<Integer> out)
static void levelOrder(Node root, List<Integer> out)
```
