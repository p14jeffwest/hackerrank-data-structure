The first line contains the number of commands, `Q`.

Each of the next `Q` lines contains one command.

| Command | Meaning |
|---|---|
| `push X` | Put `X` on the top. No output. |
| `pop` | Print the top element and remove it. |
| `peek` | Print the top element. |
| `size` | Print the number of elements. |
| `empty` | Print `1` if the stack is empty, `0` if not. |
| `clear` | Remove everything. No output. |

`pop` and `peek` on an empty stack print `empty`.
