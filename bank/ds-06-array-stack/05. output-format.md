Print one line for every command that produces output (`pop`, `peek`, `size`,
`empty`).

`pop` and `peek` print `empty` when there is nothing on the stack. If your code
reads outside the array instead, that line reads `crash`.

**The output handling is already written.** You only have to make the three
methods work.

### Example

Input

```
12
pop
peek
push 10
push 20
peek
size
pop
pop
empty
pop
push 5
size
```

Output

```
empty
empty
20
2
20
10
1
empty
1
```

The first two commands touch an empty stack. After `push 10` and `push 20` the
top is `20`, so `peek` reports it and the first `pop` takes it. The second
`pop` takes `10`, leaving the stack empty, which is why `empty` prints `1` and
the third `pop` reports `empty`.
