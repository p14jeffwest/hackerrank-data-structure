The first line contains the number of commands, `Q`.

Each of the next `Q` lines contains one command.

| Command | Meaning |
|---|---|
| `enqueue X` | Add `X` to the queue. No output. |
| `dequeue` | Print the oldest element and remove it. |
| `empty` | Print `1` if the queue is empty, `0` if not. |

`dequeue` on an empty queue prints `empty`.
