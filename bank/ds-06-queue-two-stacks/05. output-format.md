Print one line for every command that produces output (`dequeue`, `empty`).

`dequeue` prints `empty` when the queue holds nothing. If your code reads
outside an array instead, that line reads `crash`.

**The output handling is already written.** You only have to make the three
methods work.

### Example

Input

```
11
enqueue 1
enqueue 2
enqueue 3
dequeue
enqueue 4
dequeue
dequeue
dequeue
empty
dequeue
empty
```

Output

```
1
2
3
4
1
empty
1
```

Note the fourth command. `1` leaves the queue, then `4` is added, and the
elements that follow still come out as `2`, `3`, `4` -- in the order they
arrived, not in the order the stacks happen to hold them.
