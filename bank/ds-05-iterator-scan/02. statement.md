## Editing a List While You Walk It

Walk the list once and rewrite it in place:

- an **odd** value gets a `0` inserted immediately after it
- an **even** value is replaced by ten times itself

```
1 2 3 4 5     ->     1 0 20 3 0 40 5 0
```

Complete the `transform` method:

```java
public static void transform(LinkedList<Integer> list)
```

The list is modified in place; return nothing. `LinkedList<T>` and all input
and output handling are provided.

### Two ways to reach an element

The list offers both, and they do not cost the same.

| By position | With a cursor |
|---|---|
| `size()`, `get(i)`, `add(i, x)`, `set(i, x)` | `cursor()`, then `hasNext()`, `next()`, `add(x)`, `set(x)` |

`ListCursor<T>` is the `ListIterator` of section 5.4 reduced to what this
problem needs. `next()` steps over one element and returns it, `add(x)` inserts
just before the cursor -- that is, right after the element `next()` last
returned -- and `set(x)` replaces that element.

Both routes give the right answer. Only one of them finishes.
