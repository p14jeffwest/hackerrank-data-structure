For each test case, print the rewritten list on one line, with the values
separated by single spaces. An empty list prints `(empty)`.

**The output handling is already written.** You only have to change the list.

### Example

Input

```
3
5
1 2 3 4 5
4
-3 -2 0 7
0

```

Output

```
1 0 20 3 0 40 5 0
-3 0 -20 0 7 0
(empty)
```

In the second test case, `-3` is odd and keeps its value with a `0` placed
after it; `-2` becomes `-20`; `0` is even and ten times zero is still zero;
`7` is odd. Note the blank line in the input for the list of length 0.
