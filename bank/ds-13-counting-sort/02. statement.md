## Counting Sort

Sort `n` integers into ascending order. Every value lies between `0` and
`maxValue`.

**Do not compare the values with one another.** Count how many times each
value occurs and use those counts to decide where each one goes -- three
passes, none of them a comparison:

1. count the occurrences of every value,
2. turn the counts into a running total, so each value knows where its block
   begins,
3. place the values into that block.

```
[2, 0, 2, 1, 1, 0]  ->  0 0 1 1 2 2
```

```java
static int[] countingSort(int[] a, int maxValue)
```

This costs $O(n + maxValue)$ rather than $O(n \log n)$, and it is the step
radix sort is built from.
