## Leaves and Height

Given a binary tree, report three numbers.

**The number of leaves.** A leaf is a node with **no children at all**. A node
with one child is not a leaf.

**The height, counted in edges.** The number of edges from the root down to
the deepest leaf. A tree of one node has height `0`.

**The maximum depth, counted in nodes.** The number of nodes on that same
path. A tree of one node has depth `1`.

The last two measure the same thing in different units, and this course uses
both: section 9.1 counts edges, and section 9.5 counts nodes. Whenever a
problem talks about how tall a tree is, check which one it means.

### Example

```
        5
       / \
      3   8
     / \    \
    1   4    9
```

The leaves are `1`, `4` and `9` -- three of them. `8` has a right child, so it
is not a leaf. The deepest path runs `5` to `3` to `1`: **2 edges**, or
**3 nodes**.

Building the tree and all input and output handling are provided. Fill in the
three methods:

```java
static int countLeaves(Node node)
static int height(Node node)      // in edges;  empty subtree = -1
static int maxDepth(Node node)    // in nodes;  empty subtree = 0
```
