## Sliding Window Maximum

A window of `k` consecutive elements slides along an array of `n` numbers, one
position at a time. Report the maximum inside it at every position.

```
nums = 1  3 -1 -3  5  3  6  7      k = 3

[1  3 -1] -3  5  3  6  7   ->  3
 1 [3 -1 -3] 5  3  6  7    ->  3
 1  3 [-1 -3  5] 3  6  7   ->  5
 1  3 -1 [-3  5  3] 6  7   ->  5
 1  3 -1 -3 [ 5  3  6] 7   ->  6
 1  3 -1 -3  5 [ 3  6  7]  ->  7
```

There are `n - k + 1` windows, so that many answers.

Recomputing the maximum of each window costs $O(nk)$, and `n` reaches 500,000
here. What makes an $O(n)$ pass possible is that most elements can be ruled
out permanently: once a later element is at least as large as an earlier one,
the earlier one will never be the maximum again while both are in view.
