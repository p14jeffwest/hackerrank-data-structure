For each test case, print the `n - k + 1` window maxima on one line, separated
by single spaces, from the leftmost window to the rightmost.

### Example

Input

```
3
8 3
1 3 -1 -3 5 3 6 7
8 1
1 3 -1 -3 5 3 6 7
8 8
1 3 -1 -3 5 3 6 7
```

Output

```
3 3 5 5 6 7
1 3 -1 -3 5 3 6 7
7
```

With `k = 1` every element is its own window, and with `k = n` there is a
single window covering the whole array.
