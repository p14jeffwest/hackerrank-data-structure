## Binary Search Tree

In a **binary search tree**, every key in a node's left subtree is smaller
than that node's key and every key in its right subtree is larger. The rule
holds at every node.

Implement three methods:

```java
static Node insert(Node root, int key)      // returns the subtree's root
static Node search(Node root, int key)      // the node holding key, or null
static Node deleteKey(Node root, int key)   // returns the subtree's root
```

`insert` and `deleteKey` return the subtree root because it can change: the
caller writes `root = insert(root, key);` and a recursive call is written the
same way.

### The one place the shape is ambiguous

Removing a node with **two children** can promote either the largest key on
its left or the smallest on its right. Both keep the tree valid.

**Use the largest key in the left subtree.** The two choices produce
different trees, and the preorder output shows the difference.
