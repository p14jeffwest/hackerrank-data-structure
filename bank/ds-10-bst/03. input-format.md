The first line contains the number of commands, `M`.

Each of the next `M` lines contains one command.

| Command | Meaning |
|---|---|
| `insert x` | Insert `x`. A key already present changes nothing. No output. |
| `delete x` | Remove `x`. A key not present changes nothing. No output. |
| `search x` | Print `YES` if `x` is in the tree, `NO` otherwise. |
| `print` | Print the keys in ascending order. |
| `preorder` | Print the keys in preorder. |
