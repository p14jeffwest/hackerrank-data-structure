## Merging K Sorted Lists

You are given `k` lists, each already in ascending order. Merge them into a
single ascending list.

```
[1,4,5]  [1,3,4]  [2,6]   ->   1 1 2 3 4 4 5 6
```

```java
static int[] mergeKLists(int[][] lists)
```

Only the **front** of each list can be the next smallest value, so at most `k`
values are ever candidates at once. Scanning all `k` fronts at every step is
$O(N \cdot k)$ and is too slow here.

A list may be empty.
