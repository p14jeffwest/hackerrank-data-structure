## Counting Inversions

`N` integers stand in a row. Count the pairs where an **earlier value is
larger than a later one** -- the pairs `(i, j)` with `i < j` and
`a[i] > a[j]`. Such a pair is an **inversion**.

**Equal values are not an inversion.**

| Values | Answer | Why |
|---|---|---|
| `3 1 2` | `2` | `(3,1)` and `(3,2)`; `(1,2)` is in order |
| `1 2 3 4` | `0` | already ascending |
| `4 3 2 1` | `6` | every pair |
| `2 2 1` | `2` | the two `2`s are equal, so that pair does not count |

With 200,000 values there are nearly 20 billion pairs, so checking them one by
one will not finish -- and the **answer itself does not fit in an `int`**.

Merge sort compares the same pairs in $O(n \log n)$, and the count can be
worked out from what its merge step already knows.

```java
static long countInversions(int[] a)
```

You may rearrange `a`.
