For each test case, print the rotated list on one line, with the elements
separated by single spaces.

**The output handling is already written.** You only have to return the right
list from `rotate`.

### Example

Input

```
2
5 2
1 2 3 4 5
3 4
1 2 3
```

Output

```
4 5 1 2 3
3 1 2
```

In the first case, rotating twice moves `5` to the front and then `4` ahead of
it, so the last two elements lead and the first three follow.

In the second case `k` is larger than the list, and four rotations of a
three-element list land in the same place as one.
