## Rotating a List

Rotating a list **one slot to the right** moves the last element to the front
and shifts everything else back by one.

```
[1, 2, 3, 4, 5]   ->   [5, 1, 2, 3, 4]
```

Given a list and a positive integer `k`, return the list rotated `k` slots to
the right. Note that `k` may be much larger than the list itself.

Complete the `rotate` method:

```java
public static ListInterface<Integer> rotate(ListInterface<Integer> list, int k)
```

`Array_List<T>` is provided in full -- the same class you built in the previous
problem -- along with all input and output handling. Recall that `get(i)` on an
array-based list is $O(1)$.
