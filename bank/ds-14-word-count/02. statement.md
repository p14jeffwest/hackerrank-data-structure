## Counting Words

A list of words is given, with repeats. Then come queries: for each, report
**how many times that word appears in the list**. A word that never appears
counts `0`.

### Example

List:

```
apple banana apple cherry banana apple
```

| Query | Answer |
|---|---|
| `apple` | `3` |
| `banana` | `2` |
| `cherry` | `1` |
| `durian` | `0` |

Both the list and the queries are large, so scanning the list once per query
will not finish.
