## Merging Two Sorted Lists

Two linked lists are each already sorted in ascending order. Merge them into a
single sorted list.

```
1 -> 3 -> 5
2 -> 4          ->    1 -> 2 -> 3 -> 4 -> 5
```

Complete the `mergeSorted` method:

```java
public static Node mergeSorted(Node head1, Node head2)
```

**Relink the nodes you were given.** Do not create new ones, and do not copy
data from one node into another. Merging a linked list should move no data at
all -- only references.

The driver enforces this. It records every node it hands to your method and
then checks the list you return against that record, so a merged list built
out of fresh nodes is rejected even when every value in it is correct.

Either list may be empty, and both may be empty at once.

```java
class Node {
    int data;
    Node next;
}
```
