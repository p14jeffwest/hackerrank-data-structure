The first line contains the number of test cases, `T`.

Each test case is three lines:

- a line with the two list lengths `n` and `m`, separated by a space
- a line with the `n` values of the first list, in ascending order
- a line with the `m` values of the second list, in ascending order

**A list of length 0 is given as an empty line**, which is still present in the
input and still has to be read.
