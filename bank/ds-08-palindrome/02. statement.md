## Palindrome

A string that reads the same forwards and backwards is a **palindrome**.

| String | Result |
|---|---|
| `level` | `true` |
| `python` | `false` |
| `Level` | `false` |

**Upper and lower case are different characters.** `Level` starts with `L` and
ends with `l`, so it is not a palindrome.

Complete the `isPalindrome` method using **recursion**:

```java
static boolean isPalindrome(String s)
```

All input and output handling is provided.

Compare the two outer characters, then narrow the range inwards. Note that
`isPalindrome` alone has no way to say which part of the string is still under
examination -- a helper method carrying those positions is the usual answer,
and it is a pattern worth getting used to.
