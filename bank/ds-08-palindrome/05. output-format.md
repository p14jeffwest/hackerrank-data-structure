For each string, print `true` if it is a palindrome and `false` otherwise, one
per line.

**The output handling is already written.** You only have to return the right
value.

### Example

Input

```
6
aba
abba
a
Level
aa
ab
```

Output

```
true
true
true
false
true
false
```

A string of one character has nothing to compare, so it is a palindrome.
